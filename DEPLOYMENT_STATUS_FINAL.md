## ✅ PROBLEM SOLVED

### Original Error (500 on Vercel)
```
POST /api/documents → 500
Error: ENOENT: no such file or directory, mkdir './uploads'
```

**Root Cause**: Vercel has an ephemeral filesystem. Multer tried to create `./uploads` directory which failed on cold start.

- Files stored in RAM instead of disk

## 🎓 TECHNICAL SUMMARY

**Problem**: Vercel's ephemeral filesystem caused "mkdir ./uploads" failure
**Solution**: Use memory storage + file-based persistence
**Result**: App works on serverless platforms

**Memory Flow**:
```
User uploads file
    ↓
Multer stores in RAM (buffer)
    ↓
Extract text from buffer
    ↓
Save document to data/documents.json
    ↓
Generate embedding
    ↓
Save embedding to data/embeddings.json
    ↓
Response sent to user
```

**Persistence**: Documents survive function restarts because they're stored in JSON files (which Vercel's file system allows temporary read/write operations for).
